Hibi (日々, "day after day") tracks **claims**: sentences in documents that assert something checkable. The documents can be anything: a README, `CLAUDE.md`, an ADR, a pricing page, a process note in a knowledge repository. Hibi reports which claims are stale, which documents cannot be trusted right now, which sentences contradict each other, and which sentences nothing could verify.

Hibi runs nothing and fetches nothing. An agent collects evidence and submits it. The primary user is a coding agent; JSON is the contract.

## Three kinds of claim

| kind | where its truth is observed | what makes it stale |
|---|---|---|
| `code` | one or more code spans | an anchored span changed, disappeared, or matches several places |
| `reference` | one span in another document | the span changed, or the judge finds it no longer supports the sentence |
| `attested` | outside the repository: a dashboard, a vendor page, a person | its `ttl` ran out since the last judged evidence or human vouch, or submitted evidence refutes it |

## The agent loop

Before an agent relies on a document, it runs `hibi check --doc <file>`; exit 2 means a sentence in it is stale, and the verdicts say which one and what to do. When it writes or reviews a document, it runs `hibi audit --doc <file>` to see which sentences are claims of which kind and records them with `hibi record`. After a code change, `hibi check --since origin/main` names the sentences the change invalidated. Periodically, `hibi check` lists a worklist of claims to re-check; the agent follows each claim's procedure, collects what it observed, and submits it with `hibi evidence`. The judge decides whether the evidence supports the sentence. Only judged evidence or a human vouch resets a claim's ttl.

## What hibi will and will not do

- **Same tree, same verdicts.** Anchor resolution is deterministic. Judge verdicts are cached in `.claims/judge/` by model and exact request and never re-asked.
- **A flag means re-verify.** Hibi never rewrites prose and never declares a sentence false on its own authority.
- **Nothing clears without evidence or a human.** An agent vouch is recorded and does not reset a ttl.
- **One knob.** `judge.threshold` (default 0.8) decides every judge outcome. Every rule that fires is a reason label in the output.
- **No key, no silent pass.** Without `TYPESAFE_API_KEY`, a judgment the cache cannot answer is `pending`, a warning.
